Storage, indexing and retrieval

Node.js 24 and SQLite/FTS5. Originals are retained by record ID and path; per-well indexes join inspections, repairs and regulator events. Report files are followed through report_file rather than guessed filenames. Manuals, SOPs and repair reports are indexed. Additional datasets are validated and loaded alongside the sample; identical records deduplicate and conflicting IDs fail preflight.

Reasoning and tools

Gemma produces schema-constrained plans. Literal well IDs, dates, scopes and limits are checked in code, with adjustments recorded. Domain tools calculate production from manual temperature deltas, downtime from weekly inspections, corrected spill statistics, repair costs, RCA and compliance. Report containment and interim status come from text. Statistical questions can use a read-only SQLite worker over effective public facts, with provenance IDs, a row cap and timeout. Document answers cite retrieved source clauses.

Memory and conflicting evidence

Append-only shared corrections preserve original/previous effective values, actor, reason, date and inspection-field scope. Policies match either one well or a whole type plus equipment. Private conversation history is partitioned by user and persists across chats. Ordinary claims never overwrite measurements. Competing statements remain visible; unsupported current-state claims are marked unconfirmed. Report assertions remain historical when corrections invalidate their basis.

Generative interface and resilience

The answer envelope renders a status card, table, line chart, bars, geographic map or heatmap inline. Explicit visual requests win. Every answer exposes sources, dates, calculation plan and model usage. Supported local operations and exact SOP clauses remain available during model outages, with an explicit fallback label. The challenge user picker is not production authentication.

Model, cost and next steps

Default model: gemma-4-26b-a4b-it on Google's API; OpenAI-compatible endpoints are configurable. This recorded run contains 22,544 reported input and 728 output tokens from 27 successful calls. Failed requests may not return usage. Gemma is described as free-tier by the supplied guide; invoice cost is not measured. Next: wider paraphrase/property tests, stronger semantic SQL validation, authenticated deployment and incremental imports.
